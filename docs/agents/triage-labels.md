# Триаж-лейблы

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли
с реальными строками лейблов в трекере задач этого репозитория.

| Роль в скилле (mattpocock/skills) | Лейбл в нашем трекере | Значение                                |
| --------------------------------- | -------------------- | --------------------------------------- |
| `needs-triage`                    | `needs-triage`       | Мейнтейнеру нужно оценить эту задачу   |
| `needs-info`                      | `needs-info`         | Ждём дополнительную информацию от автора |
| `ready-for-agent`                 | `ready-for-agent`    | Полностью описано, готов для AFK-агента |
| `ready-for-human`                 | `ready-for-human`    | Требуется реализация руками             |
| `wontfix`                         | `wontfix`            | Решено не делать                        |

Когда скилл упоминает роль (например, «применить лейбл готовности для AFK-агента»),
используй соответствующую строку лейбла из этой таблицы.

Правь правую колонку под тот словарь, который реально используешь, чтобы
`/triage` применял существующие лейблы, а не создавал дубли.
