# shadcn/ui и Tailwind CSS для UI-компонентов

Для оформления страниц выбирали между shadcn/ui и Mantine. Mantine ставится как
обычная npm-библиотека со своим провайдером и CSS-движком — компоненты
остаются чёрным ящиком библиотеки. shadcn/ui поверх Tailwind CSS копирует код
компонентов прямо в `apps/web/src/components/ui/`, то есть каждый компонент —
обычный код репозитория, который можно читать и менять, без runtime-обёртки
поверх приложения. Это ближе к принципу минимальных зависимостей из
AGENTS.md, поэтому выбрали shadcn/ui (стиль `base-nova`, примитивы Base UI) и
Tailwind CSS v4 как основу стилизации.
